# SENATI · Prácticas Ágiles — Semana 12

Aplicación web de apoyo al laboratorio de Scrum, Kanban y XP. Archivos principales: `index.html`, `script.js` y `styles.css`.

## Objetivo
Gestionar mejoras mediante Issues, ramas de trabajo y Pull Requests revisados hacia `develop`.

## Uso
Descarga los archivos, conserva los tres en la misma carpeta y abre `index.html` en un navegador. Se utiliza Bootstrap mediante CDN.

## Flujo
`main` → `develop` → `feature/US-XX` → PR con revisión → `develop`.

## Historias de usuario
US-01 fundamentos ágiles; US-02 tablero Kanban; US-03 estilos; US-04 textos; US-05 documentación; US-06 confirmación de eliminación.
